# 🗺️ Кадастровий Помічник PRO (Land Development & Cadastral Tool)

**Кадастровий Помічник PRO** — це сучасний інтерактивний веб-інструмент (АРМ інженера-землевпорядника), розроблений для автоматизації процесів проектування, перевірки та оформлення кадастрової документації в Україні. Застосунок дозволяє швидко працювати з межами ділянок, споруджувати будівлі, розраховувати обмеження (охоронні зони), суміжників та генерувати готові друковані форми відповідно до вимог Державного земельного кадастру (ДЗК).

---

## 🌟 Ключові можливості

*   **📐 Інтерактивне CAD-Полотно (SVG):**
    *   Візуальне відображення меж ділянки, контурів будівель та охоронних зон.
    *   Редагування вузлів (перетягування точок, додавання нових вершин) у реальному часі.
    *   **Розумне прилипання (Snapping):** Автоматичне позиціонування кутів будівель та зон обмежень до поворотних точок основної межі.
    *   Стійкість пропорцій (Aspect Ratio) при зміні розмірів екрана чи згортанні бічних панелей.
*   **🌐 Геодезичні та Географічні Розрахунки:**
    *   Автоматичний розрахунок площі за формулою Гаусса (Shoelace formula) та периметра.
    *   Розрахунок внутрішніх відстаней меж та дирекційних кутів (азимутів) з точністю до секунд у форматі DMS (`ГГ°ММ'СС"`).
    *   Перерахунок метричних плоских координат ($X$, $Y$ в метрах, де $X$ — північне зміщення, $Y$ — східне зміщення за українськими стандартами) в географічні координати WGS-84 (Lat/Lng) та навпаки.
    *   Підтримка систем координат **УСК-2000**, **СК-63** та **Місцевих систем**.
*   **📋 Кадастрова Перевірка & Валідація:**
    *   Автоматичний чек-лист готовності обмінного файлу до подачі (перевірка заповненості кадастрового номера, реквізитів ДРРП, власника, наявності суміжників та замикання меж).
*   **📝 Кадастрові Реквізити та ДРРП:**
    *   Внесення відомостей про право власності (форма власності, частка, документи-підстави).
    *   Заповнення даних Державного реєстру речових прав (ДРРП) — номери рішень, реєстраційні номери, інформація про реєстратора та обтяження.
    *   Експлікація земельних угідь за класифікатором КВЦПЗ.
*   **🖨️ Генерація Друкованих Форм:**
    *   Створення офіційного креслення — **Кадастрового плану** встановленого зразка у масштабах 1:500, 1:1000 тощо.
    *   Експорт у формат для друку (Print Layout) з автоматичним формуванням каталогів координат, таблиць суміжників, експлікації угідь та кутових штампів (кадастровий звіт).
*   **💾 Імпорт & Експорт (GeoJSON):**
    *   Можливість завантаження зовнішніх файлів GeoJSON з автоматичною картографічною проекцією на площину.
    *   Експорт створеної геометрії та метаданих назад у GeoJSON.
*   **⚡ Локальне Збереження (Session State):**
    *   Автоматична синхронізація з `localStorage` — ваші дані не втратяться при перезавантаженні сторінки або випадковому закритті вкладки.

## 🛠️ Технологічний Стек

Застосунок побудований на базі передових фронтенд-технологій для забезпечення максимальної швидкості роботи та преміального користувацького досвіду:

*   **React 19** + **TypeScript** (типізація геометрії, кадастрових моделей та суміжників).
*   **Vite 6** (миттєвий релоад та оптимізована збірка).
*   **Tailwind CSS v4** (сучасний адаптивний інтерфейс з плавними переходами, скляним ефектом та глибокими градієнтами).
*   **Motion** (колишній Framer Motion для плавних мікро-анімацій меню та переходів інтерфейсу).
*   **Lucide React** (набір високоякісних векторних іконок).

## 🚀 Запуск та Інсталяція Локально

### 📋 Вимоги
*   Встановлений **Node.js** (версії 18.x або новішої).
*   Менеджер пакетів **npm** (йде в комплекті з Node.js).

### ⚙️ Кроки для запуску:

1.  **Клонуйте репозиторій або перейдіть до директорії проекту:**
    ```bash
    cd land-dev-app
    ```

2.  **Встановіть залежності:**
    ```bash
    npm install
    ```

3.  **Запустіть сервер розробки:**
    ```bash
    npm run dev
    ```
    *Після запуску відкрийте браузер за адресою [http://localhost:3000](http://localhost:3000) (або тією адресою, яку вказано у консолі).*

4.  **Збірка для продакшну:**
    ```bash
    npm run build
    ```
    *Згенеровані статичні файли будуть збережені у теці `dist/`.*

## 📝 Геодезичні Формули та Алгоритми

Додаток реалізує стандартні математичні алгоритми, що використовуються в геодезичній практиці України:

> [!NOTE]
> **1. Обчислення площі за формулою Гаусса (метод шнурування):**
> $$S = \frac{1}{2} \left| \sum_{i=1}^{n} X_i (Y_{i+1} - Y_{i-1}) \right|$$
> Застосовується з урахуванням того, що в українській геодезії вісь $X$ спрямована на північ (вертикально), а вісь $Y$ — на схід (горизонтально).

> [!TIP]
> **2. Проекція метричних координат:**
> Оскільки стандартні GPS-координати мають формат WGS-84 (широта/довгота), для точного CAD-креслення в метрах вони перераховуються локальним методом проекції навколо географічного центру ділянки на основі довжини дуги меридіана та паралелі:
> *   $1^\circ$ по широті $\approx 111\,132$ метрів.
> *   $1^\circ$ по довготі $\approx 111\,132 \times \cos(\text{lat}_{\text{ref}})$ метрів.
